# Security and operational limits

- Owner access uses a generated 192-bit capability in a mode-0600 local file. Contact capabilities are hashed at rest and expire after 48 hours. Links are bearer credentials: anyone with a link has that role's access. This is a single-owner prototype, not a multi-tenant identity system.
- Contact acceptance precedes incident sharing. Contact accounts cannot arm sessions, create agent jobs, add contacts or write owner location. Only the acknowledged contact can join audio or resolve the session. Contacts cannot cancel on the owner's behalf.
- Access keys travel in Authorization headers. Fragments are consumed locally and removed from the URL. No CORS access is granted. CSP restricts scripts/styles to self; untrusted transcript and agent output are escaped. Request bodies, field sizes and mutation rates are bounded.
- SQLite persists transcripts and incident context locally in plaintext, protected by filesystem access. Do not import sensitive real conversations into a shared demo. Stop the server and remove `.relay` to erase the prototype's active data and rotate all capabilities. Deleting that directory does not erase copied screenshots, exports or filesystem backups.
- Speech recognition, optional STUN/TURN, mapping links, Bee and Codex are external services with their own processing policies. WebRTC peers may learn each other's IP addresses. Relay does not record audio; transport audio may traverse the configured TURN provider.
- Read-only Codex sandboxing and a scoped prompt reduce action risk; the per-task directory is not a dedicated VM or a claim that all host files are inaccessible. Do not run this with privileged accounts or secrets exposed unnecessarily. Use a dedicated user/container boundary before supporting arbitrary repositories or untrusted multi-user requests.
- This service never calls emergency services or contacts people outside the accepted in-app contact workflow. It cannot detect an accident, identify an attacker or infer medical conditions. An exact spoken phrase can be replayed or spoken by someone else; arming limits exposure but does not authenticate the speaker.
- Browsers can sleep or be suspended, especially on mobile. Closed dashboards do not receive alerts. No notification receipt is inferred from queueing. A connection failure or acknowledgement is not a declaration of safety. Network-restricted audio may need TURN; no universal audio-connectivity claim is made.
